# Curiosity — Calendario Fiscal: versiones

Este repositorio solo sirve para publicar las versiones nuevas del programa.
El código fuente está en otro repositorio privado.

Para publicar una versión nueva:
1. Sube CalendarioFiscal.exe en la sección **Releases** → **Create a new release**
   (con el mismo nombre de archivo, CalendarioFiscal.exe).
2. Cambia el número de "version" en version.json.
